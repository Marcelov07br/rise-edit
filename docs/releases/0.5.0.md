# 0.5.0 — new editor base (UI stage 1 of 5)

- AMOLED theme: pure black background, white details and neutral grays. The green accent and
  colored lanes are gone; no dynamic color.
- New toolbar: horizontally scrolling icon + short label (Vídeo, Estabilizar, Cortar, Texto,
  Áudio, Overlay, Cor, Movimento, Formato). Tools open a compact panel docked just above the
  toolbar with a spring animation; the preview stays visible. Back or ✓ returns to the toolbar.
- Contextual toolbar: tapping a clip shows Dividir, Velocidade, Estabilizar, Volume, Cortar,
  Cor, Movimento, Excluir (audio/overlay/text layers show their own actions). New compact
  Velocidade (constant 0.25×–4×) and Volume panels.
- Undo/redo are always visible in the top bar, next to settings and Exportar.
- Timeline starts with three lanes (Vídeo, Overlay 1, Áudio 1). Other lanes appear when used
  or via "+ Faixa"; empty lanes have a small "+" to add media directly.

Engine and project format unchanged.
