# Rise Edit 0.4.0

- Verificação de codec, profundidade de cor e suporte do aparelho antes de importar vídeos.
- Proxies H.264/AAC locais, com progresso e cancelamento, para fontes que podem ser normalizadas.
- Prévia Rápida por padrão e modo Fiel para conferir a composição completa. Falhas no modo Fiel retornam à Rápida com aviso.
- Cortes, cursor global e acesso aos demais clipes preservados quando um arquivo está indisponível.
- Estabilização aproximada na prévia Rápida, reutilizando a análise de movimento.
- Projetos antigos continuam compatíveis; arquivos originais e assinatura do aplicativo preservados.

Validação: 23 testes JVM e 14 testes Android aprovados no GitHub Actions (run 38178856495), incluindo exportação.

Limites: fontes sem decoder nativo, incluindo APV em aparelhos incompatíveis, exigem conversão externa. A prévia Rápida não mostra texto, overlays e áudio extra; use Fiel. Redução do tamanho do APK e refatoração P2 ficam para uma próxima entrega. A confirmação da instalação continua sendo feita pelo Android.
