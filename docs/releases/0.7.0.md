# Rise Edit 0.7.0

## Barra de ferramentas com subcategorias
- Tocar numa ferramenta troca a barra inferior pelas suas subferramentas, com "<" fixo à esquerda (voltar desfaz um nível).
- Texto: Adicionar texto, Modelos, Fontes, Estilos, Efeitos, Animações.
- Áudio: Música, Efeitos sonoros, Gravar (narração pelo microfone), Extrair (áudio de um vídeo).
- Overlay: Adicionar overlay, Opacidade, Mesclagem (Clarear, Escurecer, Chroma verde), Máscara (círculo, arredondada, linear, com suavização e inverter).
- Cor: Ajustes, Filtros. Clipe selecionado: Dividir, Velocidade, Volume, Estabilizar, Cortar, Cor, Animação, Excluir.
- Só subferramentas com parâmetros abrem um painel compacto.

## Transformações só na prévia
- Removidos todos os controles de posição, tamanho e rotação dos painéis (Movimento saiu). Mover, escalar e girar: gestos na prévia; toque duplo restaura; ◆ adiciona keyframe.

## Editor de texto estilo CapCut
- Campo de texto com expandir e ✓, abas Modelos, Fontes, Estilos, Efeitos e Animações.
- Estilos: linha de predefinições "Aa", subabas Texto / Traço / Brilho / Plano de fundo / Sombra, cores com conta-gotas (captura do vídeo) e roda de cores, opacidade.
- Negrito, itálico, alinhamento, espaçamento entre letras e altura da linha.
- Fontes incluídas (SIL OFL 1.1): Inter, Montserrat, Bebas Neue, Playfair Display, Poppins.
- Animações de entrada e saída: Fade, Subir, Descer, Pop, Zoom, Digitar.
- A prévia atualiza enquanto você digita; o mesmo renderizador desenha a prévia e a exportação.
- Formato do projeto v5 (migração automática).
