# Rise Edit 0.4.1

- Redução do APK com R8, remoção de recursos não usados e bibliotecas nativas ARM64/ARMv7.
- Preserva as funcionalidades da 0.4.0, projetos existentes e assinatura do aplicativo.
- Corrige o quadro preto ao retornar de Fiel para Rápida com a prévia pausada.
- O build de testes continua suportando x86_64; uma variante otimizada também passa pelos testes no emulador.

APK otimizado local de aproximadamente 41,4 MB, contra 146,4 MB da 0.4.0 (cerca de 72% menor). Validação com R8: 15 testes Android aprovados, incluindo estabilização, exportação e pixels reais de preview; 23 testes JVM também aprovados.

Checagem final do GitHub Actions: 15 testes Debug e 15 otimizados aprovados, incluindo a visibilidade dos controles após alternar o preview.

Esta release para instalação em celulares suporta ARM64 e ARMv7. P2 (refatoração) permanece para a próxima etapa. As limitações de formatos e da prévia Rápida da 0.4.0 continuam aplicáveis.
